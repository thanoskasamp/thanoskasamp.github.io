Objective:

This project was designed to enhance the accessibility of public transportation in the neighborhoods of Toumpa and Ano Poli in Thessaloniki. The focus was on using geospatial data analysis to understand how easily people can walk to their nearest bus stops.

Methodology:

Analysis
  1. Data Collection: The data was collected from OpenStreetMap using the OSMnx Python library, which included information about buildings, streets, and bus stop locations.
  2. Data Processing: The data was cleaned and organized to ensure it was accurate and usable for analysis. Python scripts were employed to align all data to a common format for detailed examination.
  3. Network Analysis: Calculated the shortest walking routes to bus stops by connecting buildings to the closest points on the walking network, determining the most efficient paths for pedestrians.
  4. QGIS Application: QGIS was used to produce static maps that visually represent the data and analysis results, providing clear geographic visualizations of walking routes and accessibility.
WebGIS
Frontend
  1. Interactive Mapping with Folium: Created dynamic, interactive maps using the Folium Python library as the front-end mapping solution.
Backend
  1. Docker: Containerized services to simplify deployment and manage multiple components seamlessly.
  2. PostGIS: Utilized as a spatially enabled PostgreSQL database for robust geospatial data storage and querying.
  3. GeoServer: Distributed geospatial data via OGC standards (WMS, WFS) to power the interactive maps.
  4. NGINX Reverse Proxy: Configured to route requests to GeoServer securely.
  5. Certbot SSL: Automated SSL certificate issuance and renewal to ensure secure HTTPS connections.

Results:

  • The analysis provided a comparison of how accessible public transportation is in both neighborhoods. It showed differences in walking distances and times to bus stops, identifying areas where access could be improved.
